# NeoCaptain Labs

NeoCaptain Labs is the public tools and workflow lab of [Neohime](https://neohime.com/).

We start with questions that appear in real creative work, research, and independent projects. Then we turn the useful answers into readable specifications, reusable workflows, and tools that can be built with an AI agent.

## Public Projects

### Knowledge Radar

Collect RSS, newsletters, and other reading sources in one place. Use AI to apply your own relevance rules, deduplicate coverage, and deliver the signals worth your attention to the channel you actually check.

[View Knowledge Radar →](https://github.com/Neo-Captain-Labs/knowledge-radar)

## How We Work

- Clarify the problem before automating it.
- Use AI for first-pass triage and organization. Keep human judgment and action with the person doing the work.
- Share reusable methods without exposing private sources, accounts, or credentials.
