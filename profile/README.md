# NeoCaptain Labs

氖機智造的公開工具與工作流實驗室。

我們從真實的創作、研究與獨立工作問題出發，把有用的解法整理成容易理解、可重複使用，也能交給 AI Agent 建置的規格與工具。

## 公開專案

### 知識雷達

把 RSS、電子報與其他閱讀來源集中，再由 AI 依照你的規則初步篩選、去除重複訊息，最後把值得你注意的內容送到你真正會查看的地方。

[查看 Knowledge Radar →](https://github.com/Neo-Captain-Labs/knowledge-radar)

## 我們怎麼做

- 先釐清問題，再決定要不要自動化。
- AI 負責初步整理與篩選，人保留判斷與行動。
- 分享可重複使用的方法，不公開私人來源、帳號與憑證。

## 關於氖機智造

[氖機智造](https://neohime.com/) 探索 AI 創作、設計、科技與創意工作中實際可用的工作流。
